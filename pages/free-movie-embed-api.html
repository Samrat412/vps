How VidCore Movie Embed API Works

Identify Your Movie

Find the TMDB ID for the movie you want to embed. You can search for movies on themoviedb.org and extract the ID from the URL. For example, if the URL is themoviedb.org/movie/550, the TMDB ID is 550.

Construct the Embed URL

Build your VidCore embed URL using the format: https://vidcore.created.app/embed/movie/{tmdb_id}. Replace {tmdb_id} with your actual movie ID number.

Create the Iframe

Insert a standard HTML iframe element into your webpage with the VidCore URL as the source. Specify appropriate width and height attributes or use responsive CSS.

Customize Player Settings

Add URL parameters to customize player behavior: enable/disable subtitles, set autoplay, choose default quality, control player theme, and more.

Test and Deploy

Preview your embedded player across different devices and browsers. Once satisfied, deploy your changes. VidCore handles all streaming infrastructure automatically.

Glossary: Developer Terminology

API (Application Programming Interface)
A set of protocols and tools allowing different software applications to communicate. VidCore's API enables websites to embed movie players.
HLS (HTTP Live Streaming)
An adaptive streaming protocol developed by Apple that breaks video into small chunks delivered over HTTP, allowing quality adjustment based on bandwidth.
TMDB (The Movie Database)
A community-driven database providing comprehensive movie and TV show metadata including titles, descriptions, cast, crew, and images.
Adaptive Bitrate Streaming
Technology that automatically adjusts video quality during playback based on available network bandwidth and device capabilities.
Iframe
An HTML element that embeds another document within the current page, commonly used to embed third-party content like video players.
Subtitle Synchronization
The process of aligning subtitle timestamps with audio/video playback to ensure text appears at the correct moments.
CDN (Content Delivery Network)
A distributed network of servers that delivers content to users based on geographic proximity, reducing latency and improving load times.
Transcoding
Converting video from one format to another, often creating multiple quality versions for adaptive streaming.
WebVTT (Web Video Text Tracks)
A W3C standard format for displaying timed text tracks such as subtitles, captions, and chapters in HTML5 video.
Responsive Design
Web design approach ensuring interfaces adapt smoothly to different screen sizes and orientations across devices.

Troubleshooting Common Issues

Player Not Loading

Problem: The iframe displays but shows a blank or error screen.
Solution: Verify the TMDB ID is correct and the movie exists in the database. Check browser console for error messages. Ensure your website allows iframe embedding (no X-Frame-Options blocking).

Subtitles Not Appearing

Problem: Subtitles don't display even when enabled.
Solution: Confirm subtitle availability for the specific movie. Try manually selecting a different language. Clear browser cache and reload. Some older browsers may require updated subtitle support.

Buffering or Low Quality

Problem: Video buffers frequently or plays at low resolution.
Solution: Check internet connection speed. The player automatically selects quality based on bandwidth. For testing, try lower resolutions manually. Consider implementing preloading strategies on your page.

Cross-Origin Errors

Problem: Console shows CORS or cross-origin policy errors.
Solution: These are typically normal for embedded content and don't affect functionality. If playback is affected, ensure you're using the official VidCore domain and not a proxy.

Mobile Playback Issues

Problem: Video doesn't play on mobile devices.
Solution: Many mobile browsers block autoplay. Remove autoplay parameter or ensure user interaction triggers playback. Test on actual devices, not just emulators.
